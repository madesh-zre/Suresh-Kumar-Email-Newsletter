A NOTE ON BETTER COMMUNICATION

A clearer message. A better next step.

A short newsletter about making everyday communication easier to follow. Start with one useful change, then build from there.

 

Make the next action obvious.

A reader should not have to search for the point. Put the main idea first, keep the supporting detail together, and finish with a specific next step.

A quick check before you send

✓ Give the message a clear, useful heading.
✓ Keep each paragraph focused on one idea.
✓ Use link text that explains the destination.
